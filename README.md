# ❓ Frequently Asked Questions

### ❓ What is a Smile Code?

Smile Codes are digital voucher cards issued by payment networks to recharge game accounts. This API automates their verification and activation.

### ❓ Can I use this API to create a automated code selling shop?

Yes, you can use the validator to verify codes submitted by users or suppliers before listing them or processing payments.
